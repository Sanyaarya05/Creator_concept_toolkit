# Creator & Concept Toolkit

Vite + React + Tailwind CSS app prepared for Vercel deployment.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Upload this project to GitHub, then import the repository into Vercel.
Vercel should detect Vite automatically:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
